# Coleção de Filmes

## Descrição
A coleção de filmes foi desenvolvida em HTML, CSS & JavaScript, que permite 
o usuário criar sua própria coleção de filmes.
O usuário pode adicionar um título de um filme, marcar filmes como assistidos ou não assistidos
e excluir o filme que já foi adicionado.

## Objetivo
O objetivo é criar uma aplicação simples para criar sua própria
coleção de filmes e praticar conceitos fundamentais de desenvolvimento web.
O projeto permite colocar em prática os conhecimentos de:
- DOM;
- Eventos de JavaScript;
- Arrays e objetos;
- Funções;
- Estruturas condicionais;
- Métodos como `find()` , `filter()` , `LocalStorage`;
- JSON;
- Criação dinâmica de elementos HTML;
- Responsividade do CSS.

  ## Tecnologias Utilizadas
 - HTML = estrutura da página;
  - CSS = estilização da página;
  - JavaScript = lógica e funcionalidades;
  - DOM = manipulação e criação dos elementos da página;
  - LocalStorage = armazenamento dos filmes;
  - JSON = conversão dos dados para armazenamento.

## Funcionalidades
- Adicionar filmes pelo título;
- Marcar um filme como assistido ou não;
- Excluir filmes da coleção;
- Salvar filmes automaticamente no navegador;
- Carregar os filmes ao abrir a aplicação;
- Validar o cadastro impedindo adicionar filmes sem título;
- Exibir mensagens de erro ou sucesso;
- Diferenciar visualmente os filmes assistidos ou não assistidos.

  ## Como Executar
  1. Abaixe ou clone o projeto;
  2. Abra a pasta do projeto;
  3. Execute a aplicação
